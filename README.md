# Джарвис — голосовой ассистент для Windows

Локальный голосовой ассистент: слушает микрофон, отвечает голосом и **умеет делать
вещи на компьютере** — открывать программы и сайты, ставить напоминания, узнавать
погоду, читать буфер обмена, управлять звуком, искать в интернете.

Понимает речь через **Groq Whisper** (облако, точно) или офлайн **Vosk**,
думает через бесплатный **Groq** API (`openai/gpt-oss-20b`), говорит через
Windows SAPI. Можно не только говорить, но и **писать** вопросы в то же окно.

## Что умеет

- **Голос**: wake-word «Джарвис», ответы вслух, стриминг по предложениям (низкая задержка).
- **Текст**: печатаешь вопрос в окно — отвечает так же, без микрофона.
- **Действия через tool-calls модели**:
  - «открой ютуб», «запусти калькулятор», «включи музыку»;
  - «какая погода в Москве» (wttr.in);
  - «напомни через 15 минут выпить таблетку» — озвучит и переживёт перезапуск;
  - «найди рецепт борща» — откроет поиск;
  - «прочитай, что я скопировал» — читает буфер обмена вслух;
  - «сделай тише», «поставь на паузу», «сделай скриншот», «заблокируй компьютер»;
  - «который час», «какое сегодня число».
- **Локальные команды без сети**: приложения, сайты, громкость, медиа, скриншот,
  блокировка, выключение — мгновенно, из `commands.json`.

## Установка

```powershell
# 1. Зависимости (Python 3.10+)
pip install -r requirements.txt

# 2. Офлайн-модель распознавания (нужна для работы без облака)
python tools/getmodel.py          # маленькая, 45 МБ
# или лучше:
python tools/getmodel.py --big    # vosk-model-ru-0.42, 1.8 ГБ, точнее

# 3. Ключ Groq (бесплатный): https://console.groq.com → API Keys
setx GROQ_API_KEY "gsk_..."
# или положи ключ в файл .groq-key.txt рядом с assistant.py (он в .gitignore)

# 4. Запуск
run.bat
```

## Режимы

| Команда | Что делает |
|---|---|
| `run.bat` | голос + печать одновременно (по умолчанию) |
| `python assistant.py --console` | только текст, без микрофона |
| `python assistant.py --devices` | список микрофонов |
| `python assistant.py --mic 3` | выбрать микрофон по индексу |
| `python assistant.py --stt vosk` / `--stt cloud` | офлайн / облачное распознавание |
| `python assistant.py --ask "2+2"` | один вопрос модели |
| `python assistant.py --test` | самопроверка окружения |
| `python tools/mic_test.py` | проверить микрофон: уровень сигнала + распознавание |

## Как это работает

```
микрофон → VAD (нарезка фраз) → Groq Whisper (облако) ─┐
                                или Vosk (офлайн)      ├→ текст → команды / LLM →
                                                      ┘   tool-calls → действия → голос
```

- Тихую речь усиливает auto-gain, «фантазии» Whisper на шуме отбрасываются.
- Ответ модели стримится: ассистент начинает говорить с первого предложения.
- Память диалога — последние 12 сообщений.

## Безопасность

- Ключ API **не хранится в репозитории**: только через `GROQ_API_KEY` или
  локальный `.groq-key.txt` (в `.gitignore`).
- Приватные данные и настройки (микрофон, напоминания) — локальные файлы в `.gitignore`.
